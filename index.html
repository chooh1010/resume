저는 문제를 재현하고
결과를 검증하는 백엔드 개발자입니다.

Java와 Spring Boot를 중심으로 백엔드 서비스를 개발하고 있습니다.
기능이 정상적으로 동작하는 것에서 멈추지 않고, 서비스의 데이터와 트래픽이 증가했을 때 어떤 문제가 발생하는지 직접 재현합니다.
AI가 작성한 코드나 일반적으로 알려진 해결 방법도 그대로 적용하지 않고, 테스트 결과를 통해 현재 시스템에 효과가 있는지 검증하는 개발자가 되고자 합니다.

1

재현

대용량 데이터와 부하테스트로 실제 트래픽이 몰리는 문제 상황을 만듭니다.

2

측정

JMeter, Prometheus, Grafana를 활용하여 시스템의 정확한 병목 지점을 확인합니다.

3

개선

Scale Out, Read Replica 등 현재 상황과 원인에 맞는 적절한 해결책을 적용합니다.

4

검증

개선 전후의 TPS, 응답시간, 에러율, CPU 사용률을 객관적인 지표로 비교합니다.
